 # 📊 Dataset & Feature Engineering

- **Total Data:** 25.979 pertandingan historis sepak bola Eropa.
- **Pencegahan Leakage:** Menggunakan *Temporal Split* (80% Train masa lalu, 20% Test masa depan).
- **Fitur Utama:** True Elo Rating dinamis, Rolling Goal Scored/Conceded (Anti-Leakage), dan status Knockout Leg.
