## 🏆 About ChampIntel AI

**ChampIntel AI** is the world's most intelligent UEFA Champions League match prediction platform. Built by football analytics experts and AI engineers, it combines **XGBoost machine learning**, **SHAP explainability**, and **Qwen 2.5 LLM** to deliver predictions you can trust.
